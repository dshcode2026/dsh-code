# dsh-code

DSH（DeepSeek Harness）插件开发工作区。

## 插件

### dsh-what-to-eat（今日美食）

按你配置的时间，从本地菜库加权随机抽一道菜，推送到右侧栏面板和常驻浮动卡片。

- 目录：[`plugins/dsh-what-to-eat`](plugins/dsh-what-to-eat)
- 安装：`dsh plugin add dsh-what-to-eat`（[npm](https://www.npmjs.com/package/dsh-what-to-eat)）
- 文档：[插件 README](plugins/dsh-what-to-eat/README.md) · [English](plugins/dsh-what-to-eat/README.en.md)
- 验证与发布记录：`docs/`

## 开发

```bash
cd plugins/dsh-what-to-eat
npm test
```
