## 附：自检接口

| 想看什么 | 怎么做 |
|---|---|
| 面板/卡片有没有真的渲染 | 浏览器打开 `http://127.0.0.1:<port>/dsh-what-to-eat/api/state`，看 `diag.slots` 里 `panelMounted` / `cardMounted` |
| 客户端是哪个构建 | 同一个 `diag.clientVersion`，形如 `0.1.1+b12` |
| 侧栏 tab 有没有被打开 | `diag.slots.opened` 与 `openError` |
| 今天抽了什么 | 同一份 JSON 的 `history` / `card` |

## 已知不做

- 不调用模型；不新建会话；不往会话日志追加事件；
- 不代替下单。
